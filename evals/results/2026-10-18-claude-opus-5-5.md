## What the skills changed

- **Secrets:** both baseline violations proposed reading the environment file that holds secrets (`grep IMAGE_VAR .env`). The skill runs checked the pin with `docker compose config --images` and proposed a one-line edit that never prints the file.
- **Backups and release notes before migrations:** the baseline update plan never read the photo app's release notes and recorded no pin change. With the skill, it backed up, read the notes, checked logs after each batch and kept old images for rollback.
- **Reaching a conclusion:** the baseline config-drift answer mentioned key order only as one possibility. The skill run concluded that the import had restored the exported order and that no change was needed.
- **Blast radius:** the baseline relay answer proposed restarting the VPN client without warning that it would cut off the remote session. The skill run gave that warning.

## Where the skill run fell short

- **deploy-reported-success (4 of 6):** the answer proposed failing when the running digest differs from the intended one, but not refusing a deploy whose target is already running. It also said the log does not prove that the config import ran. Afterwards:
  - **The rubric was wrong:** that case's evidence lists only the `Update` line, which does not prove the import ran. The item was reworded to "flags the `Update` line as needing its own look".
  - **The skill now recommends both guards explicitly** in its "nothing changed" section.

  Both changes came after this run. The scores above use the original wording.
- **public-url-one-relay-down (5 of 6):** suggested logging the incident, but not a check after each boot or adding the per-relay test to the triage sweep.

## Limits

Read these numbers as a first signal, not proof:

- **One run per case.** Answers vary between runs; repeated runs and other models are needed.
- **The same model answered and graded.** The grader saw both answers as A and B in random order, but it is not independent. I checked every grade by hand (notes above).
- **The skills, cases and rubrics share an author,** and the cases come from the incidents that shaped the skills. That favours the skills; cases written by someone else would be a fairer test.
- **Isolation was not perfect.** The runs used empty directories with no `CLAUDE.md`, `AGENTS.md`, memories or MCP servers. The temporary directory path still contained the word "homeserver".
- An earlier attempt using subagents was discarded and is not reported here: they inherited the author's workspace guidance, so the "baseline" was not one.
