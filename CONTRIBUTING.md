# Contributing

Open an issue describing the task, client/version, observed result and desired behavior. Use sanitized code, diffs and logs. Do not include credentials, internal hosts or personal data.

Keep one workflow concern per change. Explain triggering conditions and verification; run python3 scripts/validate_toolkit.py. For new skills include name/description frontmatter, scoped steps, evidence requirements and an illustrative or real-use example labeled accurately. Avoid automatic deployments, unsupported success claims and duplicate procedures.
